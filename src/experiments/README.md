# Experiments

A space for exploratory design and technology work — prototypes, interactive concepts, and ideas that don't fit the case study format.

Each experiment lives in its own subfolder:

```
experiments/
  001-experiment-name/
    index.jsx        ← entry component
    experiment.css   ← styles (if needed)
    assets/          ← any local assets
```

These will eventually be linkable from the portfolio's Experiments section.
